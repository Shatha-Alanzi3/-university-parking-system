# 🚗 University Parking Reservation System

نظام ويب متكامل لإدارة وحجز مواقف السيارات الجامعية، يهدف إلى تسهيل عملية البحث عن مواقف شاغرة وتقليل الازدحام داخل الحرم الجامعي.

## 🌟 الميزات (Features)
- **تصفح الخدمات:** التعرف على رؤية وخدمات نظام المواقف.
- **نموذج حجز تفاعلي:** إمكانية تحديد نوع الموقف (عادي / VIP)، رقم اللوحة، والمدة الزمنية.
- **تأكيد الحجز:** عرض إشعار فور تأكيد عملية الحجز.
- **تصميم متجاوب:** واجهة مستخدم مريحة ومتناسقة مع مختلف الأجهزة.

## 🛠️ التقنيات المستخدمة (Tech Stack)
- **HTML5:** لبناء هيكل الصفحات.
- **CSS3:** لتنسيق الواجهات والتصميم المتجاوب.

## 📁 هيكل المشروع (Project Structure)
- `index.html` - الصفحة الرئيسية.
- `about.html` - صفحة من نحن ورؤية المشروع.
- `services.html` - صفحة الخدمات المتاحة.
- `booking.html` - نموذج طلب حجز موقف.
- `confirmation.html` - صفحة إشعار تأكيد الحجز.
